# NextKDE organization

- `profile/README.md`: the GitHub organization profile.
- `website/`: the public product website, hosted on GitHub Pages at <https://nextkde.github.io/.github/>.
- `.github/workflows/website.yml`: hosted browser checks and automatic website deployment.

Website source changes are published after the hosted checks pass. See [website/README.md](website/README.md) for asset provenance and maintenance notes.
